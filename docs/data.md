# Data available
## 1 - Download Data
- `data/raw/full_wq_data.csv`: All of the observations from the USGS site 
- `data/model_inputs/measured_data.csv`: A 3-column dataframe containing the measured DOC (in mol/L) and discharge (in mm/d) for the selected site
- `data/model_inputs/forcing.csv`: The forcing data for the model. Contains the precipitation (column "ppt"), air temperature (column "temp"), and potential evapotranspiration (column "pet"), with the date as the first column.
