# Potions Tutorial
This is a repository containing scripts and snippets showing how to do many things with the project, including streamflow modeling and reactive transport modeling. This is the functionality tested and explained:

## Hydrology
- Loading and constructing the model inputs
- Running a pre-defined model structure
- Viewing and parsing the model outputs
- Defining a new model structure
- Defining a new hydrologic zone
- Use scipy to do some light model calibration using multiple streamflow objectives

## Reactive Transport
- Loading and viewing the chemical database
- Defining a reaction network to describe your problem
- Constructing the model inputs for _this_ model instance
- Defining your own species for the model (primary, secondary, mineral, adsorption)
- Defining your own kinetic reactions (TST and Monod)
- Running the reactive transport model forward
- Using scipy to do some light model calibration using multiple species
